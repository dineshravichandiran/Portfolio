Root Cause Analysis

Triage Java application logs in Sumo Logic, validate Zabbix infrastructure alerts, monitor URL performance via Catchpoint, and produce trend analysis for recurring issues to drive permanent fixes.

05

Alert Optimization

Spearheaded memory alert tuning — analyzed firing patterns, adjusted thresholds, and reduced false positives. Cut noisy on-call pages and improved signal-to-noise ratio for the rotation team.

Proactive updates during outages with clear ETAs and status. Coordinate SSL/cert renewals across App, DB, and Incident teams. Execute weekend maintenance windows with zero-customer-impact targets.
